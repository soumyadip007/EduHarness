# Pilot Execution Protocol (Runbook)

## Timeline
- Week 0: consent + pre-test
- Weeks 1–3: tutoring sessions
- Week 4: post-test + surveys

## Session Rules
- At least 2 sessions/week/student
- 20–40 minutes/session
- Log exam-mode prompts separately

## Data Pipeline
- Export traces, escalation logs, patch logs
- Anonymize using participant IDs
- Store scoring sheet and survey exports
