# Pre/Post Test Blueprint — Python Module

## Test Structure
- 10 questions (100 marks total)
- 2 each from variables, conditionals, loops, functions, lists/strings

## Sample Items
1. Swap two values in Python.
2. Use if-elif-else for grade classification.
3. Sum 1..N using a loop.
4. Explain when to use while over for.
5. Write a function for factorial.
6. Write a palindrome checker.
7. Count vowels in a string.
8. Find max value in list without max().
9. Debug a faulty loop.
10. Explain benefits of function abstraction.
