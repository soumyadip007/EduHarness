# EduHarness User Guide

Welcome to the complete user and developer guide for **EduHarness**.

EduHarness is a research and engineering platform for **trustworthy agentic tutoring**.  
It combines:

- LLM tutoring (agent response generation)
- Verification and pedagogical controls
- Durable learner memory across sessions
- Teacher governance and intervention workflows
- Research evaluation and experiment analysis

Use this documentation to understand the full system, run it locally, configure models, and improve it beyond prototype/hardcoded behavior.

## Who this guide is for

- **Researchers** who want to run harness experiments and ablations.
- **Backend engineers** who want to extend APIs and control logic.
- **Frontend engineers** who want to improve dashboard UX.
- **Teachers/instructional designers** who want governance visibility and control.

## Start here

1. Read `System Guide -> Overview`
2. Read `System Guide -> How It Works`
3. Follow `System Guide -> Setup & Run`
4. Configure models in `System Guide -> Model Configuration`
5. Use `System Guide -> Improvement Roadmap` to remove hardcoding and productionize.
